# company-deck — 프롬프트 한 방에 회사 양식 그대로 발표 자료 만들기

유튜브 「AI는 훌륭하다」 영상에서 쓴 Claude 스킬입니다.
회사 발표 자료 하나와 이번에 쓸 자료(메모, 엑셀, 회의록)를 주면, AI가 회사 양식을 재서 새 발표 자료(PPTX)를 만들고, 스스로 검사하고 고쳐서 가져옵니다.

## 준비물

- 파워포인트
- Claude 유료 요금제(월 20달러 프로 이상)와 Claude 데스크톱 앱의 Code 탭

## 쓰는 법

1. 빈 폴더를 하나 만들고 그 안에 `자료` 폴더를 만듭니다.
2. `자료` 폴더에 넣습니다.
   - 회사 발표 자료 하나 (PPT 파일이나 PDF)
   - 이번 발표에 쓸 자료 전부. 대충 쓴 메모, 엑셀, 회의록, 로고 무엇이든 됩니다. 정리하지 않아도 됩니다
3. Claude 앱의 Code 탭에서 그 폴더를 엽니다.
4. 아래 프롬프트를 붙여 넣습니다.

```
https://github.com/kyusieun/company-deck 에 있는 company-deck 스킬을 이 폴더의 .claude/skills 에 설치하고, 설치한 SKILL.md를 읽고 그대로 따라 줘.
자료 폴더에 우리 회사 발표 자료랑 이번 발표에 쓸 자료들(메모, 엑셀, 회의록 같은 것)을 넣어 뒀어. 회사 양식 그대로 발표 자료 만들어 줘.
자료에 없는 내용은 지어내지 말고, 나한테 묻지 말고 끝까지 해 줘.
```

5. 끝나면 `결과` 폴더에 `발표자료.pptx`가 생깁니다. `결과/보고.md`에 AI가 정한 결론, 계산한 숫자, 채워야 할 칸이 적혀 있습니다.

## 알아 둘 것

- 숫자는 마지막에 한 번 직접 확인하세요.
- 자료에 없어서 못 채운 칸은 `[자료 없음]`으로 표시됩니다.
- 한글(hwp) 파일은 PDF로 저장해서 넣어 주세요.
- 회사 자료를 AI에 올려도 되는지 회사 규정을 먼저 확인하세요.
