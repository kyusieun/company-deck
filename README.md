# company-deck

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

회사에서 실제로 발표한 자료 한 벌을 본보기로 삼아, 메모·엑셀·회의록으로 같은 양식의 새 발표 자료를 만드는 Claude Code 스킬입니다.

![회사 자료(왼쪽)와 이 스킬로 만든 슬라이드(오른쪽)](assets/side_by_side_1.jpg)

본보기 자료의 글자 크기, 색, 제목과 쪽 번호 위치를 코드로 측정해서 슬라이드를 만들고, 파워포인트로 열어 검사합니다. 그다음 작업 내용을 모르는 다른 Claude 세션에게 새 슬라이드와 본보기 슬라이드를 섞어 보여 주고 새 것을 골라내게 합니다(아래에서 "감별"). 지적받은 곳을 고치고, 남은 문제는 보고서에 적습니다. 결과는 파워포인트에서 고칠 수 있는 PPTX입니다.

## 준비물

| 준비물 | 설명 |
|---|---|
| 윈도우 PC와 설치형 파워포인트 | 만든 슬라이드를 파워포인트로 열어 검사합니다. 웹판 파워포인트로는 안 됩니다 |
| Claude 유료 요금제 | 무료 요금제로는 쓸 수 없습니다 |
| Claude Code | [설치 안내](https://code.claude.com/docs/ko/setup)대로 설치하고, 처음 실행할 때 Claude 계정으로 로그인합니다. 모델은 `/model`로 Opus를 고릅니다 |
| 본보기 자료에 쓰인 글꼴 | 없으면 가장 가까운 글꼴로 바꿉니다 |

작업하는 동안 본보기 자료와 입력 자료는 Anthropic으로 보내집니다. 개인 요금제에서는 설정에 따라 대화 내용이 모델 학습에 쓰일 수 있습니다. 회사 자료를 AI 서비스에 올려도 되는지 소속 회사의 규정을 먼저 확인하세요.

## 시작하기

1. 빈 폴더를 만들고 그 안에 `자료` 폴더를 만듭니다.
2. `자료` 폴더에 넣습니다.
   - **본보기 자료 한 벌** (PPTX 또는 PDF). 빈 템플릿보다 표와 차트가 들어간, 실제로 발표한 자료가 좋습니다. 표·차트·도식의 모양을 이 자료에서 가져오기 때문입니다. **파일 이름에 "양식"을 넣고, 그런 파일은 하나만 둡니다.** 예: `2분기실적_양식.pptx`
   - **이번에 쓸 자료.** 메모(txt, md), 엑셀(xlsx, csv), 워드(docx), PDF, 로고 그림을 읽습니다. 정리하지 않아도 됩니다.
3. 그 폴더에서 Claude Code를 엽니다. 윈도우 탐색기에서 폴더 빈 곳을 오른쪽 클릭 → "터미널에서 열기" → `claude` 를 입력하면 됩니다.
4. 아래 프롬프트를 붙여 넣습니다. [프롬프트.txt](프롬프트.txt)와 같습니다.

```
먼저 이 컴퓨터에 Python과 Node.js가 있는지 확인하고, 없으면 설치해 줘.
그다음 https://github.com/kyusieun/company-deck 저장소를 내려받아서(git이 없으면 ZIP으로) skill/company-deck 폴더를 이 폴더의 .claude/skills/company-deck 으로 복사하고, 그 안의 tools 폴더에서 npm install 을 해 줘. 복사한 뒤 내려받은 저장소 사본은 지워 줘. 그리고 .claude/skills/company-deck/SKILL.md 를 읽고 그대로 따라 줘.
자료 폴더에 우리 회사 발표 자료(이름에 '양식'이 들어간 파일)랑 이번 발표에 쓸 자료들(메모, 엑셀, 회의록 같은 것)을 넣어 뒀어. 회사 양식 그대로 발표 자료 만들어 줘.
자료에 없는 내용은 지어내지 말고, 나한테 묻지 말고 끝까지 해 줘.
```

권한 설정이 기본값이면 명령을 실행하거나 파일을 쓸 때마다 확인 창이 뜹니다. 허용을 눌러야 진행됩니다.

몇 장으로 만들지, 어떤 순서로 할지는 메모에 적으면 따릅니다. 로고를 바꾸려면 로고 그림을 넣고 메모에 바꿔 달라고 적습니다.

### 결과

| 파일 | 내용 |
|---|---|
| `결과/발표자료.pptx` | 만든 발표 자료 |
| `결과/발표자료.pdf` | PDF로 내보낸 미리 보기 |
| `결과/쪽그림/` | 슬라이드마다 그림과 모아 보기 |
| `결과/보고.md` | 고른 본보기 파일, 정한 결론과 이유, 계산한 숫자와 계산식, 줄이거나 뺀 내용, 감별 결과, 채워야 할 칸, 남은 문제 |

- 글자는 파워포인트에서 바로 고칠 수 있습니다. 막대 차트는 파워포인트 차트로 만들어질 때도 있고 도형으로 그려질 때도 있습니다. 도형으로 그려진 막대는 숫자를 고쳐도 길이가 바뀌지 않습니다. 표와 도식은 도형과 글 상자로 그려집니다.
- 본보기 자료의 슬라이드 마스터는 이어 쓰지 않습니다. 슬라이드를 더할 때는 비슷한 슬라이드를 복제해서 고칩니다.
- 같은 폴더에서 다시 만들면 `결과` 폴더의 파일을 덮어씁니다. 손본 파일은 다른 이름으로 저장해 두세요.
- 측정한 본보기 값은 `작업/양식`에 남습니다. 같은 본보기로 다시 만들면 측정을 건너뜁니다. 다른 본보기로 바꿀 때는 새 폴더에서 하거나 `작업/양식`을 지웁니다.

스킬을 새 버전으로 바꾸려면 `.claude/skills/company-deck` 폴더를 지우고 이렇게 보냅니다.

```
https://github.com/kyusieun/company-deck 저장소의 skill/company-deck 폴더를 이 폴더의 .claude/skills/company-deck 으로 복사하고 tools 폴더에서 npm install 까지만 해 줘. 발표 자료는 만들지 마.
```

## 예시: 메모·엑셀·회의록으로 만든 분기 실적 보고

OCI의 공개 실적발표 자료(21장)를 본보기로 쓰고, 가상 회사 "한결소재"의 3분기 영업실적 자료를 넣었습니다. 입력 자료는 시험을 위해 일부러 정리하지 않은 상태로 꾸며 쓴 것입니다.

- 메모 12줄: 결론은 적지 않았고, "장표는 10장 안으로", "로고는 우리 로고로 바꿔주고 회사 이름은 한결소재" 같은 요청이 들어 있습니다.
- 월별 실적 엑셀: 시트 4개에 담당자 칸과 빈 시트가 그대로 있습니다.
- 회의록과 로고 그림.

사람에게 묻지 않고 9장을 만들었습니다.

![결과 9장](assets/result_9pages.jpg)

왼쪽은 본보기로 쓴 OCI 자료, 오른쪽은 만든 슬라이드입니다. 그림 위에 적힌 번호는 PDF 파일 안의 순서입니다.

![OCI 자료와 만든 슬라이드 비교](assets/side_by_side_2.jpg)

결론과 구성은 AI가 자료를 보고 정했습니다. 회의록에서는 발언자와 담당자 이름을 빼고 결정 사항과 할 일만 가져왔습니다. 엑셀에 없던 1·2분기 제품별 합계, 지역별 분기 합계, 비중, 증감률은 계산해서 넣고 계산식을 `보고.md`에 남겼습니다.

이 작업은 감별을 통과하지 못했습니다. 고친 뒤에도 Claude 감별은 새 슬라이드 6장을 모두, GPT 감별은 5장을 골라냈고, 본보기 슬라이드 4장은 둘 다 고르지 않았습니다. 가장 먼저 든 이유는 로고였습니다(요청에 따라 한결소재 로고로 바꿨기 때문입니다). 그 밖에 표의 줄 간격이 성기다는 점, 막대가 세 개뿐이라 넓다는 점, 상자 안이 비어 보인다는 점을 지적했습니다. 다른 메모로 한 앞선 시험에서 로고를 원래대로 되돌리고 채점했을 때도 새 슬라이드가 대부분 골라졌습니다. 로고 말고도 차이가 남아 있습니다.

## 동작 방식

```mermaid
flowchart LR
    A[자료 모으기] --> B[본보기 측정]
    B --> C[구성 짜기]
    C --> D[슬라이드 만들기]
    D --> E{검사}
    E -- 실패 --> D
    E -- 통과 --> F{감별}
    F -- 지적됨, 두 번까지 --> D
    F -- 통과 또는 두 번 고친 뒤 --> G[PPTX와 보고.md]
```

1. **자료 모으기**: `자료` 폴더에서 본보기 파일을 고르고, 나머지 자료를 한 파일로 모읍니다. 본보기가 PPTX면 파워포인트로 PDF를 만들어 씁니다.
2. **본보기 측정**: 글자 크기와 줄 간격, 색, 선 굵기, 제목과 쪽 번호 위치, 모든 슬라이드에 되풀이되는 요소를 측정합니다. 파워포인트로 시험 삼아 한 번 내보내서 글자가 놓이는 위치의 오차도 구해 둡니다.
3. **구성 짜기**: 결론을 정하고 슬라이드마다 전할 말을 하나씩 나눕니다. 표, 차트, 도식 같은 슬라이드 종류는 본보기에 있는 것 가운데서 고릅니다.
4. **슬라이드 만들기**: 본보기의 부품과 치수를 가져와 새 내용에 맞게 배치합니다.
5. **검사**: 파워포인트로 내보낸 결과를 다시 측정해서 여백, 되풀이 요소, 글자 크기, 색, 정렬, 자료에 없는 숫자를 확인합니다.
6. **감별**: 이 PC의 `claude` 명령으로 새 세션을 띄워 슬라이드 그림만 보여 줍니다. 그 세션에는 그림을 여는 도구만 주고, 권한 확인은 끈 상태로 띄웁니다. 새 슬라이드가 골라진 비율이 본보기 슬라이드가 골라진 비율보다 높지 않으면 통과입니다. 지적된 이유는 본보기와 대조해서 사실일 때만 고칩니다.

`SKILL.md`에는 지난 제작에서 검사에 걸리거나 감별에 지적된 사례와 대처가 정리돼 있습니다. 특정 회사의 값은 들어 있지 않고, 필요한 값은 매번 그 본보기에서 측정합니다.

## 시험 결과

모두 명령줄(Claude Code CLI)에서 권한 확인을 끈 상태로, Opus 5.5로, 조건마다 한 번씩 돌렸습니다. 제작 비용은 만드는 데 쓴 토큰을 API 정가로 환산한 값이고, 감별 비용은 Claude 감별분만 적었습니다. 유료 요금제에서 한 번 돌릴 때 사용량 한도를 얼마나 쓰는지는 재지 않았습니다.

| 시험 | 도구 | 장 | 시간 | 제작 비용 | 감별 비용 |
|---|---|---|---|---|---|
| 설치 경로 확인 (PPTX 본보기, 링크로 설치) | 커밋 9e0e0ae | 6장 | 약 15분 | 3.7달러 | 0.3달러 |
| 위 예시 (OCI, 메모·엑셀·회의록) | 공개 전 버전 | 9장 | 약 19분 | 5.8달러 | 0.7달러 |
| 검증 실험 (삼성SDS, 뺀 세 장 다시 만들기) | 공개 전 버전 | 3장 | 27분 | 5.9달러 | 3.0달러 |

설치 경로 확인은 빈 폴더에서 저장소를 링크로 받아 설치하는 것부터 시작했습니다. 본보기로 이 스킬이 앞서 만든 보고서를 넣었기 때문에 감별 결과는 싣지 않았습니다. 그 뒤 프롬프트와 `SKILL.md`를 조금 고쳤습니다.

### 검증 실험: 공시 자료에서 뺀 세 장 다시 만들기

삼성SDS의 2026년 1분기 실적발표 자료(21장)에서 4·5·6번째 슬라이드를 뺐습니다. 남은 18장과 뺀 슬라이드의 글·배치 메모를 주고 다시 만들게 한 뒤 원래 자리에 넣었습니다. 본보기를 얼마나 따라 하는지 재려는 실험입니다.

![삼성SDS 21장 중 4·5·6번째를 AI가 다시 만든 결과](assets/quiz_21pages.jpg)

21장을 모두 두 감별(Claude Fable 5.1, GPT 5.5)에 각각 세 번 보여 주고 AI가 만든 세 장을 고르게 했습니다. 글이 거의 없는 간지와 맺음 슬라이드를 빼고 아무렇게나 고른다 쳐도, 한 장이 뽑힐 확률은 다섯 번에 한 번 정도입니다.

| 슬라이드 | Claude | GPT | 합계 |
|---|---|---|---|
| 4번째 | 0/3 | 0/3 | 0/6 |
| 5번째 | 0/3 | 1/3 | 1/6 |
| 6번째 | 0/3 | 2/3 | 2/6 |

4번째는 한 번도 골라지지 않았고, 6번째는 아무렇게나 고를 때보다 자주 골라졌습니다. 글과 배치를 정해 준 조건이라, 메모만 주는 실제 사용보다 쉬운 시험입니다.

## 문제가 생기면

- **중간에 멈췄을 때**: 같은 대화에서 "이어서 끝까지 해 줘"라고 보냅니다. 사용량 한도에 걸렸으면 한도가 풀린 뒤에 보냅니다. 창을 닫았으면 그 폴더에서 `claude --continue`로 이전 대화를 연 뒤 보냅니다.
- **글자 모양이 다를 때**: 본보기에 쓰인 글꼴이 PC에 있는지 확인합니다. `보고.md`에 바꾼 글꼴이 적혀 있습니다.
- **읽지 못하는 파일**: 한글(hwp)과 옛 형식(xls, doc, ppt)은 읽지 못합니다. PDF나 xlsx, docx, pptx로 다시 저장해서 넣습니다.
- **엉뚱한 파일이 본보기로 쓰였을 때**: `보고.md` 첫머리에 고른 파일이 적힙니다. 본보기 파일 이름에 "양식"을 넣고 다시 합니다.
- **GPT에게도 감별받고 싶을 때**: 이 PC에 `codex` 명령이 있으면 프롬프트 끝에 "감별은 codex로도 받아 줘"를 붙입니다. 이때 슬라이드 그림이 OpenAI로 보내집니다. 요청하지 않으면 쓰지 않습니다.

## 제한 사항

- 판정은 모두 감별(AI)이 했습니다. 사람이 결과를 보고 판정한 시험은 없습니다.
- 명령줄에서 권한 확인을 끈 상태로만 시험했습니다. 데스크톱 앱과 맥에서는 아직 돌려 보지 않았습니다.
- 회사가 실제로 쓰는 PPTX(슬라이드 마스터와 테마 글꼴이 있는 파일)를 본보기로 넣는 것, 회사 전용 글꼴을 쓰는 본보기는 시험하지 않았습니다. 시험한 본보기는 모두 맑은 고딕과 Arial을 썼습니다.
- Python과 Node.js를 자동으로 설치하는 과정은 시험하지 않았습니다. 회사 PC에서는 설치 권한이 막혀 있을 수 있습니다.
- `claude` 명령이 없는 PC에서는 감별을 하위 에이전트가 대신합니다. 이 경로는 시험하지 않았습니다.
- 입력 자료는 시험을 위해 꾸며 쓴 것이고, 조건마다 한 번씩만 돌렸습니다. 같은 입력이라도 실행마다 결과가 조금씩 다릅니다.
- 숫자는 자료와 대조해 검사하지만, 쓰기 전에 직접 확인해야 합니다.
